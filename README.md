Signal & Static is a shortwave radio-tuning arcade game. A faint transmission hides somewhere on a 0.0-100.0 MHz dial; sweep the dial with the mouse or A/D until the oscilloscope trace sharpens out of the static, then lock it with SPACE. A clean lock within +/-2.0 MHz decodes the message and builds your streak, a sloppy one scores little, and a lock far off burns one of your three relays. Clear three stations of four transmissions each to finish the night, before the tower clock runs out.

## Run it

```sh
cd game && python3 -m http.server 8080
# open http://localhost:8080
```
